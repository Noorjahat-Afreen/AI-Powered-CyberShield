About the project

How the ML works

CyberShield trains two scikit-learn models (train_models.py) and converts them to JavaScript so this static site can score inputs instantly, with no server:

  • Random Forest - 100 decision trees, max depth 10, majority vote over 17 URL features.
  • TF-IDF + Multinomial NB - 773 word/n-gram features, log-probability scoring.
  • Browser engine verified prediction-exact against sklearn (100% match on held-out fixtures).

Tech stack

  • Python, scikit-learn, pandas (training pipeline)
  • HTML5 + CSS3 + vanilla JS (this site)
  • Chart.js (analytics), localStorage (history), no backend needed
  • Optional AI layer: Z.ai GLM / Google Gemini via config.js

Educational project - verdicts are model estimates, not a substitute for careful browsing.
